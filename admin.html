Configuration du propriétaire

Le code d'accès est vérifié côté serveur. Il n'est pas affiché ici et ne doit jamais être placé dans le HTML ou dans un fichier public.

Pour changer le code : ouvrez Vercel → projet Atelier N° → Settings → Environment Variables, modifiez la variable ADMIN_ACCESS_CODE avec votre nouveau code, puis redéployez le site. Gardez également SUPABASE_URL et SUPABASE_SERVICE_ROLE_KEY configurées côté serveur.

Wave/Orange Money et les livraisons ne sont pas confirmés automatiquement par ce tableau de bord. Les statuts que vous modifiez sont des mises à jour manuelles.
